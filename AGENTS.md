# Local Stack

This folder is a self-contained learning, documentation, and knowledge-base workspace.

- Keep repository work, notes, and artifacts inside this folder.
- Infrastructure manifests and bootstrap scripts may reference explicitly declared host paths, system packages, services, binaries, and network endpoints required by the deployment target.
- Do not add undeclared repository dependencies or external project files.
- Prefer small, focused files and clear folder names.
- When in doubt, ask before changing scope.
